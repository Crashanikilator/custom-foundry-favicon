# Custom Foundry Favicon — V14

Módulo para Foundry VTT V14 que substitui o favicon padrão pelo ícone personalizado.

Instalação:
1. Extraia a pasta custom-foundry-favicon dentro de Data/modules/.
2. Confirme que Data/modules/custom-foundry-favicon/module.json existe.
3. Reinicie o Foundry.
4. Vá em Configuração → Gerenciar Módulos.
5. Ative Custom Foundry Favicon.
6. Recarregue a página com Ctrl+F5.
